Kulinaris als App installieren

Installiere Kulinaris direkt auf deinem Startbildschirm oder Desktop – inklusive eigenem App-Icon, Vollbildmodus und Offline-Zugriff auf deinen Wochenplan & die Einkaufsliste.

Dein Browser unterstützt die direkte 1-Klick-Installation:

🤖 Android (Chrome / Edge)

Tippe oben rechts auf das ⋮ Menü und wähle „App installieren“ oder „Zum Startbildschirm hinzufügen“.

🍎 iPhone & iPad (Safari)

Tippe unten/oben auf das Teilen-Symbol (□↑) und wähle „Zum Home-Bildschirm“.

💻 Windows / Mac / Chromebook

Klicke rechts in der Adressleiste auf das Installieren-Symbol (⊕ / 🖥️) oder im Browser-Menü auf „Kulinaris installieren“.

Tipp: Wenn du die Datei lokal geöffnet hast, lade sie einfach auf einen kostenlosen statischen Hoster (z. B. GitHub Pages, Netlify Drop oder Vercel) hoch – dann funktioniert die PWA-Installation auf jedem Gerät ohne Einschränkung.
